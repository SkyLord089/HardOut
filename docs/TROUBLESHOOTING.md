# Если «ничего не работает»

Главный принцип: сначала выясняем, **выполняется ли код**, и только потом
крутим настройки. Ниже — по шагам, за 30 секунд.

## Шаг 1. Есть ли пульс?

Открой **View → Output** и нажми Play. Должно быть:

```
[HardOut] Строю тестовый полигон...
[HardOut] Сервер готов. Оружие кладётся в ReplicatedStorage.WeaponModels.
[HardOut] Клиент готов: вид от первого лица, руки/ноги, HUD.
[HardOut] Диагностика готова: F2 — панель, /ho — статус в чат.
[HardOut:пульс] FPS 60 | кадров 60 | камера Scriptable | персонаж R15
```

| Что видишь | Вывод |
|---|---|
| Строки **есть**, пульс идёт | скрипт работает → иди в шаг 2 |
| Есть только серверные строки | `ClientBoot` не запустился (см. шаг 4) |
| Ничего нет | скрипты не попали в место (шаг 5) |

Пульс печатается раз в секунду первые 8 секунд, потом реже. Если строк
`[HardOut:пульс]` нет вообще — клиентский код не выполняется.

## Шаг 2. Работает ли камера (покачивание)

Боб включается только при **движении по земле** (>0.5 studs/s) и заметен
при `Amplitude >= 0.1`. Проверка:

1. Иди вперёд (`W`) и смотри в стену — картинка должна покачиваться.
2. В чат: `/bob 0.3` — станет явно видно. Если и с 0.3 не видно → камера
   не обновляется (шаг 3).
3. `/ho` покажет текущее значение.

Камера двигалась → в панели F2 есть строка «камера двигалась: ДА».

## Шаг 3. Если персонаж не идёт

Если нажимаешь `W` и не двигаешься — камера и движение мертвы вместе:

* мышь не заперта в центре → кликни в окно игры, затем проверь `/ho`;
* `Humanoid.WalkSpeed` обнулён, но движение не применяется (не наш код) —
  в пульсе будет `персонаж R15`, а позиция не меняется.

## Шаг 4. `ClientBoot` не запустился

Studio → Explorer → `StarterPlayer → StarterPlayerScripts`:
* должен быть **`ClientBoot`** (LocalScript);
* рядом с ним — папка **`Modules`** (не внутри `ClientBoot`!).

Если `Modules` внутри `ClientBoot` — перетащи её наружу, к соседям.

## Шаг 5. Скрипты не попали в место

Ты открыл старый `.rbxlx`. Перекачай файл из репозитория (он пересобран),
или пересобери сам: `python3 tools/build_place.py`.

Проверить файл без Studio:

```bash
python3 tools/verify_place.py HardOut.rbxlx
node tools/dom-check.js HardOut.rbxlx        # парсер rbx-dom (как в Rojo)
```

## Шаг 6. Крутить настройки в игре

| Команда | Что меняет |
|---|---|
| `/ho` | статус в чат |
| `/bob 0.3` | покачивание головы |
| `/eye 0.45` | вынос камеры из головы (видно тело) |
| `/eyeoff 0.5` | высота глаз |
| `/body on` | показать тело |
| `/head off` | показать голову |
| `/fov 80` | угол обзора |
| `/shake 0.2` | тряска от выстрела |
| `/lean 1.0` | наклон в стрейфе |
| `/smooth 0` | убрать сглаживание (1:1 с мышью) |

Подобранные числа перенеси в `src/shared/HardOut/Config.luau`.

## Почему клиент молчал (реальный случай)

```
[HardOut] НЕ НАЙДЕНА папка Modules рядом с ClientBoot
```

Причина — **гонка загрузки**. Studio создаёт объекты по одному в порядке файла.
`ClientBoot` лежал в файле раньше папки `Modules`, запускался первым и делал
`script.Parent:FindFirstChild("Modules")` → `nil` → `return`. Всё, клиент мёртв:
ни вида, ни боба, ни тела, ни курсора. Сервер при этом работал (у него порядок
случайно был удачным), поэтому «сервер есть, клиента нет».

Что исправлено:

1. `WaitForChild("Modules", 10)` вместо `FindFirstChild` — и на клиенте, и на сервере.
   Это единственно правильное чтение соседей в Roblox: `WaitForChild` ждёт,
   `FindFirstChild` — нет.
2. В `tools/build_place.py` папка `Modules` теперь пишется **первой**, до скрипта.
3. В верификатор добавлена проверка «гонка загрузки»: любой
   `X:FindFirstChild("Modules"/"HardOut"/...)` падает, если рядом нет
   `Instance.new("Folder")`. Она нашла ещё 3 таких места (`Remotes`, `CombatService`).

Важно: `script:WaitForChild(...)` (без `.Parent`) — тоже ошибка, скрипт не
сиблинг сам себе.

## Реальный случай 2: `attempt to index nil with 'hud'`

```
ClientBoot:66: attempt to index nil with 'hud'
```

`PlayerController.new()` не имел `return self` — конструктор возвращал `nil`.
Строка `controller.hud = hud` падала, и дальше не выполнялось НИЧЕГО:
ни камера, ни движение, ни оружие, ни тело. Оставались только мышь и прыжок
(их даёт сам Roblox, а не наш код).

Что сделано, чтобы не повторилось:

1. `return self` добавлен.
2. `tools/constructor-check.mjs` — проверяет, что каждый `function X.new(...)`
   возвращает объект. Включён в `npm run check:ctors`.
3. Клиент в `init.client.luau` теперь запускает шаги **по отдельности** в `pcall`:
   падение одного шага не убивает остальные и печатает точное место
   (`[HardOut] Шаг "контроллер игрока" упал: ...`).

## Реальный случай 3: прыгает сам без остановки

Причина: у пробела не было ветки `InputEnded`. Событие «Jump Ended» не
приходило никогда, флаг `jumpRequested` оставался `true` навсегда, и
`tryJump()` вызывался каждый кадр (раз в ~0.35 с — отсюда «прыжок раз в секунду»).

Исправлено:

1. `Input.luau`: пробел теперь отлавливается и в `InputEnded`.
2. `PlayerController`: флаг называется `jumpHeld`; дожим (`jumpQueuedUntil`)
   сбрасывается после одного срабатывания.
3. Страховка: если событие отпускания потерялось (Alt+Tab, потеря фокуса),
   каждый кадр сверяемся с `UserInputService:IsKeyDown(Space)`.

## Реальный случай 4: мышь «плавает»

`Config.Camera.Smoothing = 0.3` — это инерция камеры. При быстрых поворотах
прицел отстаёт от мыши. Теперь по умолчанию `0` (мышь 1:1). Если хочется
лёгкую инерцию — `/smooth 0.1`.

## Реальный случай 5: покачивание «странное и неудобное»

Что было не так:

1. **Боковое смещение прибавлялось в мировых осях** (`Vector3.new(bobX, ...)`).
   При повороте на 90° «влево-вправо» превращалось в «вперёд-назад» — главная
   причина странного ощущения. Теперь смещение считается в осях камеры
   (`cameraCFrame.RightVector`).
2. **Крен был фиксированные 1.2°** и не зависел от настройки — укачивало.
   Теперь `HeadBob.RollDegrees`, по умолчанию `0`.
3. **Вертикаль считалась как `|sin|`** — с изломами в нижней точке, отсюда
   дёрганье. Теперь гладкий синус.
4. **Амплитуда включалась скачком** на пороге 0.5 studs/s. Теперь плавно
   нарастает и затухает.
5. Амплитуда 0.16 была слишком большой → теперь 0.035 (деликатно).
6. При прицеливании покачивание ослабляется втрое.

Крутить: `/bob 0.02`, `/bob off`, `/sway 0.01`, `/roll 0.5`.

## Известные подводные камни

* **Мышь не заперта** → камера не вращается, кажется, что «скрипт мёртв».
  Кликни в окно; `PlayerController` теперь перезапирает её каждый кадр.
* **`ModuleScript` нельзя `Disabled`** → вызов падал, отключение контроллов
  не срабатывало. Теперь `Disabled` ставится только у `Script`/`LocalScript`.
* **Roblox сам скрывает тело** в первом лице → `CharacterTransparency` каждый
  кадр возвращает видимость.
* **Боб не виден при 0.045** → теперь по умолчанию 0.16.
