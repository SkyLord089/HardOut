# Как собирается `.rbxlx` без Rojo

`tools/build_place.py` пишет файл места напрямую. Формат сериализации сверен
с эталонными файлами **rbx-dom / Rojo** (а не «по памяти»), потому что Studio
молча игнорирует неправильно оформленные свойства — место открывается, но
части/скрипты не работают.

## Что важно в формате (и почему это ломалось)

| Свойство | Как надо | Что бывает при ошибке |
|---|---|---|
| `Name` | `<string name="Name">X</string>` | объекты без имён, скрипты не находят друг друга |
| `Part.CFrame` | `<CoordinateFrame name="CFrame">` с `R00…R22` | части складываются в точку 0,0,0 или не появляются |
| размер части | `<Vector3 name="size">` | часть исчезает |
| цвет | `<Color3uint8>` как упакованное число | серый/чёрный цвет |
| атрибуты | `<BinaryString name="AttributesSerialize"></BinaryString>` | `Instance:GetAttribute` может не работать |
| `Source` скрипта | `<string name="Source"><![CDATA[…]]></string>` | пустой скрипт (Studio ждёт CDATA) |
| `referent` | уникальный у каждого `<Item>` | файл не грузится целиком |

## Проверка перед открытием

```bash
python3 tools/build_place.py          # собрать
python3 tools/verify_place.py         # проверить
```

Верификатор проверяет 10 вещей, в том числе:

* есть ли пол и `SpawnLocation` (иначе «падаю и ресаюсь»);
* существуют ли `ServerBoot`, `ClientBoot`, папки `Modules`;
* **разрешаются ли все `WaitForChild` / `FindFirstChild` / `require`** по
  реальной иерархии файла — именно это ловит классический баг
  `script:WaitForChild("Modules")` вместо `script.Parent:…` (скрипт молча
  висит навсегда, полигон не строится, в игре пусто);
* уникальны ли `referent`;
* непустой ли `Source` у скриптов;
* есть ли у всех `Part` свойства `CFrame`, `size`, `Anchored`.

## Ограничения

* Модели оружия (`WeaponModels`) в файл не пакуются — кладутся руками.
* `Lighting.Technology` (Future) не задаётся: это enum, его имя в разных
  версиях Studio отличается. Поставь вручную в Properties, если нужно.
* Сборщик — не Rojo: повторный синк «живьём» не делается, после правок кода
  нужно пересобрать файл.
