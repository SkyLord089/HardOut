# Как запустить стенд: rojo.exe + плагин Studio

Коротко: **`rojo.exe` — это сервер, который отдаёт файлы проекта в Studio.
Плагин в Studio к нему подключается.** Плагин без запущенного `rojo.exe`
работать не будет — он просто не увидит проект.

---

## Шаг 0. Где лежит проект

Открывай терминал (PowerShell) в папке проекта — там, где лежит
**`default.project.json`**. Это ключевой файл, Rojo ищет его сам.

```powershell
cd путь\к\HardOut
dir default.project.json      # должен найтись, иначе ты не в той папке
```

---

## Шаг 1. Положи rojo.exe в удобное место

Не обязательно в проект. Например:

```
C:\Tools\rojo\rojo.exe
```

Если хочешь запускать командой `rojo` из любой папки — добавь `C:\Tools\rojo`
в переменную среды **PATH**:

1. Win → «Изменение переменных среды текущего пользователя»
2. `Path` → Изменить → Создать → `C:\Tools\rojo`
3. Перезапусти терминал (важно!) и проверь:

```powershell
rojo --version
```

Если PATH не настраиваешь — просто вызывай по полному пути:

```powershell
C:\Tools\rojo\rojo.exe serve
```

> Если Windows ругается «защитила ваш компьютер» (SmartScreen) — это обычная
> подпись-предупреждение для скачанных exe: «Подробнее» → «Выполнить в любом случае».
> Скачивай только с github.com/rojo-rbx/rojo/releases.

---

## Шаг 2. Запусти сервер

```powershell
cd путь\к\HardOut
rojo serve
```

Должно появиться примерно такое:

```
Rojo 7.*.*
Build: ...
Serving on 127.0.0.1:34872
```

**Окно терминала не закрывай** — это и есть сервер. Всё время, пока работаешь,
он должен быть запущен. Остановить — `Ctrl+C`.

Если пишет `default.project.json not found` — ты не в папке проекта (см. шаг 0).

---

## Шаг 3. Подключи плагин в Studio

1. Открой Roblox Studio → **New → Baseplate** (или любое пустое место).
2. Вкладка **Plugins** (сверху) → кнопка **Rojo**.
3. В панели плагина должно появиться подключение `127.0.0.1:34872`.
   Нажми **Connect**.
4. В Explorer появится папка `HardOut` (в ReplicatedStorage), скрипты
   в ServerScriptService и StarterPlayer.
5. Нажми **Play** (F5).

Если в панели пусто и написано «No projects» — не запущен `rojo serve`
или он в другой папке.

---

## Шаг 4. Проверка, что всё живо

В консоли Studio (View → Output) при запуске Play должно быть:

```
[HardOut] Сервер готов. Оружие кладётся в ReplicatedStorage.WeaponModels.
[HardOut] Клиент готов: вид от первого лица, руки/ноги, HUD.
```

И в `ReplicatedStorage` появится папка **`WeaponModels`** с демо-пушкой `HYBRID-9`.

Если видишь только одну строку из двух — второй скрипт не запустился:
проверь, что `ClientBoot` лежит в `StarterPlayer → StarterPlayerScripts`.

---

## Важные нюансы Rojo

**Папка `WeaponModels` пропадёт при пересинке.** Rojo пересобирает дерево
из файлов проекта, а модели, добавленные руками в Studio, в файлах проекта
не лежат. Поэтому:

* если хочешь держать свою модель в проекте постоянно — сохрани её как
  `.rbxm` (правый клик по модели → Save to File) и положи в проект, добавив
  в `default.project.json`:

  ```json
  "WeaponModels": {
    "$path": "src/weapons"
  }
  ```

  и тогда `src/weapons/HYBRID-9.rbxm` будет подхватываться при синке;

* если модель нужна только «поиграть сейчас» — вставляй её после подключения
  и не делай повторный `Connect`.

**`rojo build` вместо live-синка.** Если плагин не нужен:

```powershell
rojo build default.project.json -o HardOut.rbxlx
```

Получишь файл места, который открывается в Studio двойным кликом.
Пересобирать надо вручную после правок.

## Типичные ошибки

| Сообщение / симптом | Причина и решение |
|---|---|
| `default.project.json not found` | терминал не в папке проекта → `cd` туда |
| Плагин: «No projects found» | не запущен `rojo serve` |
| Плагин: «Connection refused» | сервер остановлен или другой порт (`rojo serve --port 34873`, затем в плагине указать порт) |
| `rojo` не является внутренней командой | PATH не подхватился: перезапусти терминал или вызывай `rojo.exe` по полному пути |
| Модель оружия исчезла после синка | см. «Важные нюансы» выше |
| В Studio ничего не появилось | проверь, что подключился к *нужному* месту (Baseplate), а не к пустому unsaved-месту |
