# HardOut — тестовый стенд FPS в духе Таркова (Roblox)

Каркас будущего режима: **вид от первого лица с руками и ногами**, отдача, ADS,
инвентарь-заготовка и **готовое место под модель оружия**.

Стенд запускается «из коробки»: ни одного внешнего ассета, всё процедурное.
Если папка `ReplicatedStorage.WeaponModels` пуста — сервер сам положит туда
демо-оружие `HYBRID-9`, чтобы можно было сразу пострелять.

---

## 1. Быстрый старт

### Вариант 0 — без Rojo вообще (самый простой)

В репозитории лежит собранный файл места **`HardOut.rbxlx`**.
Скачай → открой в Studio → **Play**. Ни Rojo, ни плагина, ни терминала.

Если правил код и нужен свежий файл:

```bash
python3 tools/build_place.py     # собрать
python3 tools/verify_place.py    # проверить (10 проверок, включая пути require)
```

Подробности: `docs/WITHOUT_ROJO.md` и `docs/BUILD_PLACE.md`.

### Вариант A — Rojo (удобнее, когда начнёшь писать код)

1. Установи [Rojo](https://rojo.space/) (это `rojo.exe` — им запускается сервер)
   и плагин Rojo для Roblox Studio. Пошагово — `docs/INSTALL_ROJO.md`.
2. В папке проекта (там, где `default.project.json`):

   ```bash
   rojo serve
   ```

3. В Studio: `Plugins → Rojo → Connect`.
4. Нажми **Play**.

### Вариант B — Rojo + файл места (без плагина в рантайме)

```bash
rojo build default.project.json -o HardOut.rbxlx
```

Открой `HardOut.rbxlx` в Studio и нажми **Play**.

### Что должно произойти

* Ты появляешься на полигоне в виде от первого лица: видны руки, при взгляде вниз — ноги.
* В руках демо-оружие, в правом нижнем углу патроны, снизу хотбар, в центре прицел.
* Мишени стоят на 10 / 25 / 50 / 60 м, по ним считается урон (голова — множитель).
* В консоли Studio: `[HardOut] Клиент готов...` и `[HardOut] Сервер готов...`.

## 3. Как добавить свою модель оружия

Это главное, что тебе сейчас нужно. Порядок такой:

### Шаг 1. Закинь модель

`ReplicatedStorage` → папка **`WeaponModels`** → вставь туда свою модель
(`Model`). Имя модели = имя оружия в HUD и в хотбаре.

> Папка создаётся автоматически при первом запуске. Если её нет —
> сервер создал её при старте, обнови дерево в Explorer (F5).

### Шаг 2. Добавь сокеты (обязателен только `Grip`)

Внутри модели создай **Folder** с именем `Attachments` и в нём `Attachment`-ы:

```
ТвояМодель (Model)
└─ Attachments (Folder)
   ├─ Grip      ← ОБЯЗАТЕЛЬНО: точка хвата правой рукой
   ├─ Support   ← куда встаёт левая рука (цевьё)
   ├─ Muzzle    ← срез ствола: отсюда вспышка и трассер
   └─ Sight     ← точка прицеливания при ADS
```

**Оси:** ствол смотрит в **−Z**, верх оружия — **+Y**.
Если оружие в руках смотрит не туда — крути `CFrame` самого `Grip`,
а не всю модель.

Без `Grip` оружие всё равно наденется (по центру модели) и в консоль придёт
предупреждение. `Muzzle` не обязателен, но без него вспышка будет из центра
модели, а трассеры — «из ниоткуда».

### Шаг 3. (Опционально) пропиши статы

Либо атрибутами на модели (Explorer → Properties → Attributes):

| Атрибут | Тип | Что делает |
|---|---|---|
| `RoundsPerMinute` | number | темп стрельбы |
| `Damage` | number | урон |
| `HeadshotMult` | number | множитель за голову |
| `MagazineSize` | number | ёмкость магазина |
| `ReloadTime` | number | секунды перезарядки |
| `Spread` / `SpreadAim` | number | разброс от бедра / в прицеле |
| `Recoil` | number | сила отдачи |
| `Auto` | boolean | автоматический огонь |
| `AmmoType` | string | подпись патронов в HUD |
| `AdsFov` | number | FOV в прицеле |
| `Range` | number | максимальная дистанция |

Либо просто назови модель `PM`, `AK74`, `M4`, `MP5`, `Mosin` — подхватится
готовый пресет из `src/shared/HardOut/Weapon/WeaponConfig.luau`.

### Шаг 4. Проверь

Нажми Play. В консоли будет строка вида:

```
[HardOut] Модель 'ТвояМодель' OK. Сокеты: Grip, Muzzle, Sight, Support
```

Если чего-то не хватает — увидишь `warn` с точным списком проблем.

> Удали демо `HYBRID-9` из `WeaponModels`, когда твоя модель заработает:
> стенд не будет подкладывать демо, если в папке уже что-то есть.

## 5. Как это работает внутри (коротко)

**Руки/ноги.** По умолчанию (`ViewModel.Mode = "Character"`) вид идёт через
настоящего персонажа: видны его руки, ноги и **штатные анимации Roblox**;
голова и шляпы прячутся локально, чтобы не закрывать обзор, а оружие
приваривается к настоящей кисти (`RightHand` / `Right Arm`).
Альтернатива — `Mode = "Procedural"`: процедурные руки-сегменты с IK-позами
(`ArmSolver`), без внешних ассетов.

**Оружие.** Клонируется на клиент, жёстко привязывается `Weld`-ом к правой
кисти по сокету `Grip`. Позиция `Muzzle` даёт вспышку и начало трассера.

**Стрельба.** Клиент присылает только «куда смотрел». Сервер сам считает
raycast, разброс и урон (голова ×2.2+, конечности ×0.7), рассылает трассер всем.
Поэтому «взломанный» клиент не даёт бесконечного урона.

**Отдача.** Паттерн по выстрелам (первые точные, дальше уводит вверх-вправо)
+ пружинный возврат. В прицеле разброс и отдача снижаются.

## 6. Песочница "рейдов": вес и состояния

В чате (только для стенда) работают команды:

| Команда | Что делает |
|---|---|
| `/weight 25` | вес снаряжения 25 кг → медленнее и больший разброс |
| `/fracture` | переключить перелом (скорость ×0.55) |
| `/bleed` | переключить кровотечение (скорость ×0.85) |
| `/stamina 25` | выносливость (ниже 30 — ещё медленнее) |
| `/reset` | сброс |

Формулы — чистые функции в `server/modules/RaidSandbox.luau`, они покрыты тестами.
Это заготовка под настоящую рейдовую систему (инвентарь, вес, лут, состояния).

## 7. Заметки по настройке

* Руки в кадре «не так» → `Config.ViewModel.Offset` (сдвиг всей модели).
* Слишком быстрый/медленный шаг → `Config.Movement.*`.
* Прицел слишком резкий → `Camera.luau` → `Spring.new(0, 200, 22)` (второй `aimSpring`).
* Нет ног внизу → `Config.ViewModel.ShowLegs = true`.
* Хочешь свой уровень → `Config.TestRange.Enabled = false` и строй сам.

## 8. Что специально НЕ сделано (задел на будущее)

Это стенд, а не готовый режим. Дальше логично добавить:

* **Инвентарь/рюкзак** — сейчас слоты просто отражают папку с моделями.
* **Патроны по типам** — `AmmoType` уже есть в HUD, но запас бесконечный (`ReserveAmmo`).
* **Броня и зоны** — `Penetration` в статах есть, расчёт брони не подключён.
* **Хитмаркеры/кровь/звуки** — точка подключения есть (`Tracers.luau`, `ShotSoundId`).
* **Сеть для чужих игроков** — сейчас видны только трассеры чужих выстрелов.
* **Сохранения/лут/рейды** — это уже сам режим, каркас под него — этот стенд.

## 9. Тесты и проверки

```bash
npm install              # один раз: @luau-rs/luau
npm run verify           # проверка синтаксиса + 33 юнит-теста
npm run check            # только компиляция всех .luau
npm test                 # только тесты
```

`tools/check.sh` делает то же одной командой.

Тесты гоняют настоящие модули в Luau-рантайме с моками `Vector3`/`CFrame`,
поэтому ловят ошибки в разбросе, IK, отдаче и перезарядке без запуска Studio.
